# Gym Tracking Project

## Project by Le Bao Anh Nguyen

The plan for this application is to help new gymer who doesn't know where to start in their journey, and this application is where they can get 
assisted with many different kind of exercises with the help from the chatbot, as well as tracking their performance over time. 

## Features

- Personalized workout plans
- Exercise tutorials with clear description
- Performance tracking and analytics
- Chatbot assistance for exercise guidance
- Nutrition and diet recommendations
- Goal setting and progress monitoring
- Regular updates with new exercises and features
- User-friendly interface and experience

More features will be updated in the future soon!
